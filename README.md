# Portfolio Website

This repository contains my personal portfolio website hosted using GitHub Pages.

The website showcases my profile, technical skills, projects, certifications, and contact information. It is designed as a static website and deployed publicly through GitHub Pages for easy access and sharing.

The portfolio highlights my learning journey and practical knowledge in technologies related to DevOps, Cloud Computing, Linux, Docker, Kubernetes, CI/CD, and AWS.

GitHub Pages is used to host the website directly from the GitHub repository, allowing fast and free deployment of static content.

## Features

- Personal portfolio website
- Responsive static design
- Public hosting using GitHub Pages
- Easy deployment and maintenance
- Showcases technical skills and projects

## Deployment

The website is deployed using GitHub Pages from the main branch of this repository.
